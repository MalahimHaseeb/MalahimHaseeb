# 🤖 AI Agents

I build agents that can do more than generate text.

An agent can:

```text
Understand a request
        ↓
Decide what to do
        ↓
Use tools / APIs
        ↓
Search information
        ↓
Call other agents
        ↓
Check the result
        ↓
Take an action
```

I work with:

- LangGraph
- LangChain
- OpenAI
- Gemini
- Groq
- Python
- Tool calling
- Agent memory
- Multi-step workflows
- Multi-agent systems

# 📚 RAG

I build applications where AI can work with **your own documents and data**.

Typical flow:

```text
Documents
   ↓
Read & Process
   ↓
Split into useful pieces
   ↓
Create Embeddings
   ↓
Store in Vector Database
   ↓
Search
   ↓
Give useful context to AI
   ↓
Generate Answer
```

I work with:

- Document processing
- PDF processing
- Embeddings
- Vector search

- Retrieval

- RAG evaluation
